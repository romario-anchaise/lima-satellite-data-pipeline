# Lima Satellite Data Pipeline

Proyecto de aprendizaje de ingeniería de datos con Python.

## Objetivo

Construir paso a paso un proceso para consultar, transformar
y almacenar metadatos satelitales de Lima desde Microsoft
Planetary Computer.

## Estado actual

El programa lee una ciudad desde un archivo JSON
y la muestra en la terminal.

## Ejecutar

Desde la carpeta principal del proyecto:

python3 main.py
